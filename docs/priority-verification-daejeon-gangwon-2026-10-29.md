# 대전·강원 신청 경로 및 기한 우선 검증 — 2026-10-29

> 검증 결과의 범위를 엄격히 구분한다. **공식 게시물 존재 확인**, **공식 원문 문장 대조**, **연락처 실제 통화 검증**은 서로 다른 절차다. 오늘 원문에 접근하지 못한 내용을 2026-10-29 신규 본문 확인으로 기록하지 않는다.

## 1. 대전: 학교민원대응지원팀 경로

### 확인된 내용
- 「초·중등교육법」 제37조제1항: 학교 민원대응팀, 관할청 학교민원대응지원팀 등 설치
- 제37조제3항: **학교장**은 필요한 경우 관할청에 학교민원 **처리 지원 또는 직접 처리**를 요청할 수 있음
- 제37조제4항: 학교민원 처리 절차·방법의 세부 내용은 **교육감이 정함**
- 법률 원문: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285599&chrClsCd=010202&urlMode=lsInfoP&efYd=20261029&ancYnChk=0
- 기존 대전 교육활동보호관 원스톱 방안(2026. 10. 15. 게시)은 학교 민원대응팀 → 관할 교육지원청 지원 요청·이첩의 기본 구조를 설명함. 2026. 10. 23. 원문 감사 기록 보존.

### 아직 확인되지 않은 내용
- 대전 **동부·서부 교육지원청**의 학교민원대응지원팀 **전용 접수 번호**(일반 민원, 지역교권보호위원회 번호를 임의 전용하지 않음)
- 대전교육청/대전동부/대전서부에서 실제 지정한 **특이민원 이첩 보고 양식·신청 담당부서·공문 시행 경로**
- 오늘 외부 페이지 자동 열람에서 대전 교육지원청 업무분장 URL에 타임아웃 발생; 이를 조직이 없다는 증거로 사용하지 않음.
- 비교 자료: 충북교육청 「2026 학교민원처리 매뉴얼」 부록에 '특이민원 관련 지원 요청 보고서'가 있으나, *해당 서식은 교육(지원)청별 여건에 따라 변경·활용할 수 있음*을 명시함. 따라서 충북 서식을 **대전의 확정 서식으로 복제하지 않음**.
  - https://after.cbe.go.kr/upload/dept-26/na/bbs_2019/2026/04/8EA0B09C-43CC-343E-B6B0-F76407E5DCB5.pdf (p.56/파일 60번째 페이지 부근)

### 화면 반영
- 확인된 법적 권한·처리 지원 요청 구조는 분명히 설명
- 학교 민원대응팀의 사실관계 확인 → 학교장이 관할 교육지원청에 지원/직접 처리 요청 → **접수팀·이첩 서식은 해당 관할 교육지원청에 먼저 확인**
- 별도 직통번호를 만들거나 일반 교원이 직접 팀에 이첩해야 한다고 오인시키지 않음
- `reviewBy: 2026-11-02` 그대로 유지(별도 번호·서식 계속 미확인)

## 2. 강원: 마음 건강 치료비 2026년 청구 마감

### 확인된 내용
- 강원특별자치도교육청 교육활동보호센터 자료실에서 **2026-04-03** '2026 마음 건강 치료비 지원 신청서'(게시번호 50815), '2026 교원 정신건강증진사업 시행 계획'(게시번호 50789)이 2026-10-29 현재 확인 가능한 **공식 게시 목록에 존재**.
  - https://www.gwe.go.kr/main/bbs/list.do?key=m2307211167413
- **기존 2026-10-26 공식 원문 감사**(`docs/12-region-final-accuracy-audit-2026-10-26.md`)에서는 신청서 본문에 '2026년도 치료비 청구 서류는 11. 30.까지 제출(이후 접수 불가)'라는 문구가 있음을 인용·대조했음.
- 따라서 코드의 `validUntil: '2026-11-30'`, `reviewBy: '2026-11-02'`, 상·하반기 청구기간, 연 100만 원 실비 한도는 **기존 감사 근거대로 유지**.
- 현재 자동 열람 환경에서 개별 게시물의 첨부 원문에 새로 접근하지 못했으므로 **오늘 독립적으로 첨부파일 문장을 읽은 것으로 기록하지 않음**. 게시물 목록 확인만으로 변경·연장 부재가 확정되는 것도 아님.

### 화면 반영
- 이미 timing에 적힌 **2026-11-30 청구 서류 마감(이후 접수 불가)**을 첫 지원 설명에도 표시. 기존 정책·지급액·적용 대상·연락처는 변경하지 않음.
- 프로그램 `verifiedAt: 2026-10-26`, `sourceUpdatedAt: 2026-04-03`을 임의로 오늘로 갱신하지 않음.
- 2026-11-02 원본 첨부/실무 담당자 대조와 사업비 조기 소진·접수 방식 변경 여부 확인은 미완료로 남김.
