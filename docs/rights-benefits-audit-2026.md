# 권리·보호조치·지원제도 audit (2026-10-03, 2차)

목표: “교육활동 침해 상황을 알려주는 사이트”에서 “선생님이 실제로 쓸 수 있는 권리·보호조치·지원제도까지 알려주는 사이트”로.
상단 메뉴(홈·대응 절차·상황별 도움·지원 찾기)는 그대로 두고 기존 흐름 안에 배치해요. 1차 audit은 `protection-support-audit-2026.md`.

## 7. 자동 적용으로 오해할 위험이 있는 내용

| 위험 문구 | 바른 표현 |
| --- | --- |
| 침해당하면 자동 5일 / 폭행이면 10일 | 5일의 범위에서 부여할 수 있어요 · 해당하는 경우 5일의 범위에서 추가 |
| 교권침해 인정 → 공무상 질병휴직 | 공무상 질병·부상으로 인정되는 경우(공무상 요양 승인) 확인할 수 있어요 |
| 침해 인정 → 휴직 인정 | 장기간 치료가 필요하다면 질병휴직을 검토할 수 있어요 |
| 치료비 300만 원 지급 | 인천 기준 침해 인정 교원 1인당 300만 원 범위 |
| 휴가 → 병가 → 휴직 자동 이행 | 각 제도는 적용 요건과 승인 절차가 서로 달라요 |
| 전보 요청 = 전보 확정 | 시·도 인사 기준과 심의를 거쳐요 |

점검 도구가 ‘자동 승인·지급·부여’, ‘휴직 인정’, ‘특별휴가 10일’ 같은 표현을 막아요(부정문 ‘자동 승인되는 것은 아니에요’는 허용).

## 8. 지원 검색 제안

상황 검색은 그대로 두고, 검색어가 권리·지원 이름·키워드(특별휴가·병가·휴직·치료비·공무상·변호사·경호·전보 등)와 맞으면
결과 위에 ‘권리·지원에서도 찾았어요’를 함께 보여 줘요. 범용 통합 검색은 이번 범위에서 보류해요.

## 9. 확인하지 못해 넣지 않은 것

- 사립·기간제 교원의 특별휴가·병가 세부 근거(학교법인·계약 기준)
- 공립 기간제 교원이 공무원 재해보상법 대상에서 빠진다는 법조문(매뉴얼 안내로만 표시)
- 서울 상담 1회 금액, 인천 상담 횟수, 경기 두 치료비 한도의 중복 여부
