# 1차 지역 확대 사전 조사 — 제주 · 대구 · 대전 (2026-10-19)

> **상태: 조사 착수 / 정식 지역 데이터 미등록 / Production 변경 없음.** 아래는 공식 게시 페이지에서 직접 확인할 수 있었던 항목과 추가 검증 필요 항목을 구분한 초기 기록이다. 각 게시물의 첨부 계획서·약관 본문, 현재 접수 담당·교육지원청 관할은 데이터 반영 전에 별도로 대조해야 한다. `verifiedAt` 및 `contactsVerifiedAt`을 조사 착수일로 일괄 기록하지 않는다.

## 확대 범위와 원칙

- 신규 지역 ID: `jeju`, `daegu`, `daejeon`; 기존 9개 지역을 포함한 목표 12개.
- 전국 공통 절차·상황·휴가/병가 제도는 `data/common.js`를 재사용한다. 지역 고유 데이터는 `data/regions/<id>.js`에만 넣는다.
- 새 지역마다 `registerRegion({ id, short, name, office, officeUrl, basis, verifiedAt, reviewStatus, contactsVerifiedAt, areasVerifiedAt, expectedAreas, sources, hot, hotName, hotContacts, hotSummary, links, terms, offices, programs, areaNote, orgs })`의 기존 계약을 참고한다. 일부 필드는 선택 사항이므로 실제 스키마·검사기로 확인한다.
- **대표번호·공식 담당자·법률/심리/공제 지원의 창구는 분리한다.** 112와 지역 교육활동보호센터 대표번호를 같은 용도로 표현하지 않는다.
- 금액, 회기, 지원 대상(공립·사립·기간제 등), 시행·종료일과 신청 경로는 해당 사업의 2026년 1차 공식문서와 재확인 후 반영한다. 부재·불명확 시 숨기거나 확인 필요로 기록하고 다른 지역 값으로 채우지 않는다.
- 일반 교육청 홈페이지는 지원 허브의 독립적인 '바로 이용하기' 카드로 넣지 않는다. **교육활동 보호 전용** 안내·신청 링크를 사용한다. 출처 및 푸터의 일반 홈페이지 확인 경로는 별개다.
- 새 지역을 아직 완성·검수하지 않았는데도 `index.html` 지역 스크립트에 등록하거나 공개 베타 지역으로 표시하지 않는다.
- 현재 `main` 기준 `dc43cee`(asset version `20261019-4`). 별도 미병합 브랜치 `fix/hub-direct-links-label`의 1줄 문구 수정은 추후 통합 시 충돌·누락 여부를 확인한다.
