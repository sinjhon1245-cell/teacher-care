# 공식 출처 정확도 점검 — 2026-11-04

PR #23 뒤 링크 점검에서 ‘확인 필요’로 남은 2건과 전남광주 심리상담 안내의 갱신일 차이를 공식 원문으로 다시 확인했다. 화면(UI)은 바꾸지 않았고, 지원 금액·조건·연락처는 바꾸지 않았다. 16개 지역·192개 지원 안내를 그대로 유지한다.

## 1. 부산 — 교원보호공제 약관 개정 공고

- 수정 전: `https://www.pen.go.kr/main/na/ntt/selectNttInfo.do?mi=30361&bbsId=2342&nttSn=1165028`
- 수정 후: `https://www.pen.go.kr/upload/main/na/bbs_2342/ntt_1165028/doc_29bdvca00=b4v71=42vcb=8dva5=baf7v7e54v8718_v6871.pdf` (같은 공고의 원문 첨부파일)
- **HTTP 400의 원인:** 게시글은 삭제되지 않았다. 부산교육청 서버가 세션 쿠키 없는 요청의 일부에 자체 오류 화면(‘누리집 오류 알림’, HTTP 400)을 돌려준다. 쿠키가 없을 때 400이 9/48(점검 도구 UA 5/24, 브라우저 UA 4/24), 세션 쿠키를 유지하면 0/24, 같은 게시판 목록은 쿠키 없이 0/24였다. 실제 브라우저의 새 세션 16회 중 3회도 오류 화면이었다. 그래서 우리 사이트에서 처음 누른 교원도 약 5번에 1번 오류를 볼 수 있다.
- **같은 문서 확인:** 게시글이 정상으로 열릴 때 본문은 ‘교원보호공제 약관 개정 공고’, 교원인사과, 등록일 2026.03.04, 공고 제2026-162호, 적용시기 2026. 3. 1., 첨부 ‘(붙임) 교원보호공제 약관 개정 공고(2026. 3. 1.).pdf’(318,406바이트)이다. 내려받은 PDF는 크기가 같고(318,406바이트, 45쪽), 1쪽에 ‘교원인사과 공고 제2026-162호 / 교원보호공제 약관 개정 공고 / 2026. 3.’, 운영 기간 2026. 3. 1.~2027. 2. 28.이 있다. 2025년 약관이 아니다.
- **안정성:** PDF 주소는 쿠키 없이 24/24 HTTP 200이다.
- 바꾼 값: `sources[8]` 주소·제목 끝 ‘원문 PDF’·`verifiedAt` 2026-11-04, 교원보호공제 카드 바로가기 주소·이름(‘2026 약관 개정 공고(PDF)’). 공제 카드의 내용과 `verifiedAt`, 보조 근거인 교육활동보호센터 교원보호공제 안내 페이지는 그대로다.
- 남은 점: 부산교육청 게시글 주소 자체의 간헐 오류는 기관 서버 문제다. 첨부 파일 주소는 기관이 게시글을 고치면 바뀔 수 있어 다음 정기 점검에서 다시 확인한다.

## 2. 강원 — 교권보호지원단 보도자료(글번호 57056)

- 수정 전: `https://www.gwe.go.kr/promotion/bbs/view.do?key=bTI0MTEyMjUyOTQ2NDA=&bbsSn=57056`
- 수정 후: `https://www.gwe.go.kr/promotion/bbs/view.do?key=bTI2MTEwMjkzMzg2NjA=&bbsSn=57056`
- 제안된 주소 `https://open.gwe.go.kr/promotion/bbs/view.do?bbsSn=57056&key=m2411225294640`은 **열리지 않아 쓰지 않았다.** 기존 주소의 key를 base64로 풀면 `m2411225294640`으로, 두 주소는 같은 옛 게시판 key를 쓴다. 두 주소 모두 HTTP 500 6/6, 실제 브라우저에서 `/error/error.html?id=bbs`(‘요청하신 페이지를 찾을 수 없습니다’)로 이동한다.
- **원인:** 강원교육청 누리집 메뉴의 보도자료 게시판 key가 `bTI2MTEwMjkzMzg2NjA=`(= `m2611029338660`)로 바뀌었다. 글번호 57056은 그대로다.
- **같은 원문 확인:** 수정 후 주소는 실제 브라우저에서 200으로 열리고, 제목 ‘[정책기획과 전연숙] 교권보호지원단, 교육활동 보호 위한 현장 대응 강화’, 작성일 2026-10-20, 첨부 ‘[1020]3.보도자료(…).hwpx’·‘[1020]3.붙임자료(…).hwpx’가 있다. 페이지가 자기 주소로 표시하는 형식과 같고, 쿠키 없이 16/16 HTTP 200이다.
- 바꾼 값: `sources[13]`의 주소와 `verifiedAt` 2026-11-04만. 제목·`sourceUpdatedAt`(2026-10-20)·지원 카드 내용은 그대로다.
- 참고: `open.gwe.go.kr`에 새 key를 쓰면 같은 글이 열리지만, 기존 데이터와 같은 `www.gwe.go.kr`을 유지했다.

## 3. 전남광주 — 전남권 심리상담 안내 갱신일

- 주소는 그대로: `https://www.jne.go.kr/thsupport/cm/cntnts/cntntsView.do?cntntsId=641&mi=1814` (`www.jge.go.kr`로 이동, 두 주소의 응답 내용 동일)
- **실제 갱신일은 2026-10-15이다.** 페이지 하단 ‘최근 업데이트 일시’가 2026-10-15이고, 이 값은 페이지마다 다르다(같은 사이트 법률상담 642번 2026-06-09, 공제 646번 2026-04-03).

  - `sources[4]`(업무자료실): 2026-11-04 확인 시 자료실의 신청서 게시글(2025. 10. 2.)은 2025년 서식이므로 제목에 ‘2025년’을 밝혔다.

- 남은 점: 페이지의 ‘1인당 100만원 이내’, ‘6개월 이내 신청’, ‘1년 이내 종결’ 문구는 2026-10-15 갱신에서도 바뀌지 않았다. 다만 페이지가 여전히 전라남도교육청 기준으로 적혀 있어, 통합 뒤 적용·광주권 적용 여부는 담당 부서 확인 전까지 보류한다.
