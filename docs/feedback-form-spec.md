# 의견 받기 양식(Google Form) 명세

사이트 푸터의 ‘정보가 바뀌었거나 잘못된 내용을 발견하셨나요? [알려주기]’에 연결할 설문 양식의 명세예요.

- **현재 상태: 비활성.** 관리할 공식 양식 주소가 없어서 `data/common.js`의 `FEEDBACK_URL`은 빈 문자열이고, 운영 사이트에 버튼이 보이지 않아요.
- 임의 주소를 만들거나 넣지 않아요. 아래 명세대로 양식을 만들고 관리자가 정해지면 그때 연결해요.

## 1. 양식 맨 위 안내(설명란에 그대로)

> 이 설문은 ‘선생님 곁에’ 안내 내용을 고치기 위한 것이에요. 답변은 안내 개선에만 쓰고, 개별 사안에는 답하지 않아요.
>
> **이 설문에는 학생·보호자·교직원의 이름, 학교명, 전화번호 등 개인을 식별할 수 있는 정보나 구체적인 사건 내용을 입력하지 마세요.**
>
> 지금 도움이 필요한 상황이라면 소속 학교·교육(지원)청 교육활동 보호 창구로 연락하세요. 위험하면 112.

## 2. 문항

| # | 문항 | 유형 | 선택지·안내 | 필수 |
| --- | --- | --- | --- | --- |
| 1 | 이 안내가 도움이 되었나요? | 객관식 | 도움이 되었어요 / 조금 도움이 되었어요 / 도움이 되지 않았어요 | 예 |
| 2 | 어떤 정보를 보셨나요? | 체크박스 | 홈 / 대응 절차 / 상황별 도움 / 회복·보호 / 지원 찾기 / 잘 모르겠어요 + **지역**(서울 / 경기 / 인천 / 공통) | 아니요 |
| 3 | 찾으려던 정보를 찾으셨나요? | 객관식 | 찾았어요 / 일부만 찾았어요 / 찾지 못했어요 | 아니요 |
| 4 | 이해하기 어려웠던 부분이 있나요? | 장문 | 안내: “어느 화면의 어떤 문구였는지 적어 주세요. 사건 내용은 적지 마세요.” | 아니요 |
| 5 | 잘못되었거나 바뀐 정보를 발견했나요? | 장문 | 안내: “어느 화면·어느 항목인지, 공식 안내 주소(있다면)를 적어 주세요. 개인정보·사건 내용은 적지 마세요.” | 아니요 |
| 6 | 추가되면 좋을 정보가 있나요? | 장문 | 안내: “필요한 정보의 종류만 적어 주세요.” | 아니요 |

장문 문항(4·5·6) 아래에도 같은 개인정보 안내를 한 줄씩 다시 보여 줘요.

## 3. 양식 설정

| 설정 | 값 | 이유 |
| --- | --- | --- |
| 이메일 주소 수집 | 사용 안 함 | 개인을 식별하지 않기 |
| 로그인 필요 / 응답 1회로 제한 | 사용 안 함 | 계정 정보를 남기지 않기 |
| 파일 업로드 문항 | 넣지 않음 | 캡처에 개인정보가 들어갈 수 있어요 |
| 응답 사본 보내기 | 사용 안 함 | 이메일 수집과 같아요 |
| 응답 확인 메시지 | “보내 주셔서 고마워요. 공식 자료로 확인한 뒤 안내에 반영해요. 개별 답변은 드리지 않아요.” | 기대 관리 |

## 4. 운영

- **담당자**: 양식 소유자(관리 가능한 계정)와 응답을 보는 사람을 정한 뒤에 연결해요. 담당자가 없으면 연결하지 않아요.
- **처리 순서**: 응답 확인 → 개인정보·사건 내용이 들어간 응답은 내용을 옮기지 않고 삭제 → ‘잘못된·바뀐 정보’는 공식 원문으로 확인 → `docs/annual-maintenance-checklist.md` 업데이트 절차로 반영. 제보만으로 데이터를 고치지 않아요.
- **보관**: 반영 여부를 정리한 뒤 원 응답은 정기적으로 지워요(예: 분기마다).
- **확인 주기**: 최소 월 1회.

## 5. 사이트에 연결하는 방법(양식이 준비된 뒤)

1. `data/common.js`의 `const FEEDBACK_URL = '';`에 양식 주소를 넣어요. `https://docs.google.com/forms/…` 또는 `https://forms.gle/…`만 허용돼요(`node tools/check-data.js`가 다른 주소를 막아요).
2. `node tools/check-all.js` → asset version 올리기 → 커밋·푸시.
3. 운영 사이트 푸터에 ‘알려주기’가 보이고 새 창으로 양식이 열리는지 확인해요.

연결 전후 모두 사이트는 별도 서버나 저장소를 쓰지 않아요.
