# PR #26 — 지원 경로 정확도·검토기한·자동 링크 점검(2026-11-04)

## 0. 운영 범위 및 증거 수준
- 작업 기준: `main` 9f85fb6, 16개 지역·192개 지원 안내. 신규 지원사업 등록, 금액/승계/연락처 추정, 전체 디자인 변경은 하지 않는다.
- 출처 판정은 **(1) 공식 페이지·법령 본문 확인, (2) 해당 신청·접수 경로 확인, (3) 통합 후 지원 자격·금액 확인**을 구분한다. (1)·(2)만 충족하면 (3)을 검증 완료로 바꾸지 않는다.
- `reviewBy`, `reviewStatus`는 출처 목록에 같은 해 게시물이 있다는 이유만으로 갱신하지 않는다. 기한 경과 2건과 통합 후 미확인 사항은 남겨 둔다.

## 1. 이번에 실제로 개선한 신청 경로

### 광주권 심리상담: '지원 안내'와 '온라인 신청' 분리
- 공식 [교육활동보호센터 심리상담 신청 페이지](https://forteacher.jge.go.kr/sub/page.php?mode=board&page_code=counsel_01_02&tbnum=2)에서 **상담신청 하기 / 처리결과 확인**을 안내한다.
- 기존 지역 심리상담 지원 카드에 온라인 신청 링크(type: apply)를 추가하고, 설명용 [심리상담 지원 안내](https://forteacher.gen.go.kr/sub/page.php?page_code=support_07)는 별도로 남겼다.
- 대상·상담 횟수·야간상담 운영 조건 등은 신청 화면과 공식 안내를 확인해야 하며, 전남권 이용자에게 광주권 조건이 자동 적용된다고 쓰지 않는다.

### 광주권 법률지원단: 전담변호사 전화 상담과 구분
- 공식 [법률지원단 안내](https://forteacher.jge.go.kr/sub/page.php?page_code=support_06)는 교원이 소속 학교 **내부결재** 후 교육지원청 학교지원센터에 **공문**, 광주지방변호사회에 **팩스(062-222-1305)**로 신청하는 별도 절차를 제공한다.
- 기존 **교권전담변호사 상담**(1644-9575 문의)과 **법률지원단 지원**이 같은 접수 절차인 것처럼 보이지 않도록 신청 문구를 나누고 법률지원단 공식 안내 페이지를 별도로 연결했다.
- 공식 법률지원단 페이지에 명시된 지원대상은 **초·중·고·특수학교 교원**이므로, 다른 학교급에는 자동 적용하지 않고 센터 문의를 명시한다. 별도 통합 이후 변경된 보장 금액·소송비·변호사 선임 조건도 추가하지 않았다.

## 4. CI 자동 '확인 필요' 링크 60개 — 실제 분류
2026-11-04 배포 직전(PR #25) GitHub Actions 링크 검사 로그 기준, 489개 중 정상 399·이동 30·**확인 필요 60**·끊김 0. 같은 날 지역별 분포:
- 경북 24건(교육지원청 등 연결 시간 초과)
- 울산 14건(인증서 검증 실패)
- 충북 10건(교육지원청 연결 시간 초과/비표준 포트)
- 전남광주 5건(구 전남 교육활동보호센터 도메인 연결 시간 초과)
- 세종 5건(교육청 연결 시간 초과)
- 인천 1건(교육지원청 인증서 검증)
- 부산 1건(보도자료 HTTP 400)
- 원인별: 연결 시간 초과 44건, 인증서 검증 오류 15건, HTTP 400 1건.
- **우선 검증:** 전남광주 5건 중 심리상담·법률상담·공제 신청 경로와 부산 오류 페이지. 나머지 교육지원청 관할 찾기 및 운영 자료 링크는 기관별로 묶어 브라우저에서 확인한다.
- 2026-11-04 확인된 광주권 *신규* 직접 신청 페이지 2개는 별도 공식 `forteacher.jge.go.kr` 경로이다. 이 추가가 위 기존 60건을 자동으로 해소했다는 뜻은 아니다.
- **보안 원칙:** SSL 인증서 검증을 끄거나, 접속 실패를 성공으로 간주하는 예외 목록을 만들어 검사 PASS를 조작하지 않는다. 직접 브라우저로 확인된 새 공식 주소만 기존 주소를 교체한다.
