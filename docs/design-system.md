# 화면 디자인 시스템

`style.css` 하나가 5개 메뉴(홈·대응 절차·상황별 도움·회복·보호·지원 찾기)의 모양을 모두 정해요. 새 화면이나 항목을 만들 때는 아래 부품을 그대로 쓰고, 비슷한 모양을 새 클래스로 다시 만들지 않아요. 규칙을 바꿀 때는 해당 부품의 규칙 한 곳을 고쳐요(아래에 덧붙여 덮어쓰지 않기).

## 글꼴·글자 크기

- 글꼴은 **Pretendard Variable 하나**예요(`index.html`의 jsDelivr 링크). 본문·제목·버튼·숫자 모두 같은 글꼴이에요.
- 위계는 크기와 굵기를 함께 써요: 제목 700 · 라벨·버튼 600 · 본문 400. 장식용 굵기(800 이상)는 좁은 화면 헤더의 서비스 이름 글자에만 써요.
- 크기는 `rem`으로 적어요(브라우저 기본 16px = 1rem). 사용자가 브라우저 글꼴을 키우면 글자도 함께 커져요. 여백·테두리는 px예요.

| 토큰 | 769px 이상 | 768px 이하 | 쓰는 곳 |
| --- | --- | --- | --- |
| `--fs-h1` | 30px | 26px | 화면 제목(`.page-title`) |
| `--fs-h2` | 23px | 21px | 구역 제목(`.h2`) |
| `--fs-h3` | 19px | 18px | 카드·상황 제목(`.sub-title`, `.care-cat-title`) |
| `--fs-h4` | 17px | 16px | 묶음·접이식·목록 머리(`.block-title`, `.disclosure-title`, `.action-head`) |
| `--fs-body` | 17px | 16px | 본문 |
| `--fs-sm` | 15px | 15px | 보조 설명·라벨(`.muted.small`, `.facts dt`) |
| `--fs-xs` | 13px | 13px | 배지 |

- 줄 간격: 본문 1.65, 제목 1.35, 버튼·목록 1.4.
- 문장 속 지역 전화번호(`{HOT}` 등 토큰 값)는 `T()`가 `.nowrap`으로 묶어 ‘02-’ / ‘1395’처럼 갈라지지 않아요. 데이터 문장 속 번호는 `linkifyPhone()`이 줄바꿈 없는 전화 링크로 바꿔요.

## 색

아이보리 바탕(`--bg`) + deep teal(`--primary`, 기본 행동·선택) + warm orange(`--accent`, 주의) + red(`--danger`, 긴급만). `--faint`는 흰 바탕 대비가 3.2:1이라 글자에는 쓰지 않고 아이콘·글머리표에만 써요.

## 부품

| 부품 | 클래스 | 규칙 |
| --- | --- | --- |
| 카드 | `.action`, `.support-item`, `.tool-panel`, `.block` 등 | 흰 면 + 1px `--border` + 12px 모서리. 그림자는 떠 있는 요소(지역 목록·업데이트 창·알림)에만 |
| 버튼 | `.btn` + `.btn-primary`·`.btn-secondary`·`.btn-danger` | 높이 48px 이상, 16px/600, 8px 모서리. 글자는 한 줄이 기본이고 칸이 모자랄 때만 줄을 바꿔요 |
| 선택 버튼 | `.chip` | 필터·지원 유형·비교표 열기. 버튼과 같은 8px 모서리(알약 모양 없음). 개수는 같은 줄의 보조 숫자(`.chip-count`) |
| 배지 | `.badge`, `.badge-accent`, `.tag-danger`, `.bf-badge`(`.bf-cond`·`.bf-scope`) | 4px 모서리의 13px 사각형. 상태·조건을 알릴 때만 쓰고 **버튼 안에 넣지 않아요** |
| 바로가기 줄 | `<ul class="link-list">` + `.link-row` | 제목(`.link-row-title`) + 보조 글(`.link-row-meta`, 조건·설명) + 이동 아이콘. 회복·보호 제도는 `benefitChip()`, 지원 유형은 `supportChip()`이 만들어요. 넓은 칸에서 여러 열은 `.link-list.cols` |
| 접이식 | `<details class="disclosure disclosure-box">`(따로 선 묶음) · `disclosure-line`(카드 안) | 요약 줄은 `disclosureHead(제목, 보조 설명)`로 만들어요. 제목 · 보조 설명 · 펼침 아이콘이 각각 분리되고 요약 줄 전체가 누르는 영역이에요 |
| 안내 상자 | `callout(kind, 제목, 문장 또는 목록)` | 제목은 따로 한 줄. `info`(지금 먼저 할 일·다음 단계) · `caution`(주의할 점·꼭 확인하세요·피해야 할 행동) · `danger`(즉시 안전 확보가 필요한 상황의 먼저 할 일) · `note`(놓치기 쉬워요·적용 범위·판단할 때 참고할 점) |
| 묶음 | `.block` + `.block-title` + `.block-desc` | 상세 안의 작은 갈래(함께 확인할 제도·연결 가능한 지원·지금 해볼 일·지역 기준) |
| 라벨·내용 목록 | `facts(rows)` → `<dl class="facts">` | 줄마다 얇은 선. 칸이 520px보다 좁으면(컨테이너 쿼리) 라벨이 위로 올라가요 |
| 펼침 아이콘 | `.chevron`(아래), `.chevron.right`(이동) | 모든 접이식·목록 머리·바로가기 줄이 같은 아이콘을 써요 |

## 하지 않는 것

- 장식 이모지·그라데이션·자동 애니메이션을 넣지 않아요(☎·↗ 같은 기능 기호만).
- 알약 버튼 안에 이모지와 배지를 겹쳐 넣지 않아요.
- 한 열짜리 grid는 `grid-template-columns: minmax(0, 1fr)`로 적어요(`1fr`이면 띄어쓰기 없는 긴 기관명이 칸을 밀어내요).

## 점검

화면 코드를 고치면 `tools/ui-check.js`를 360·375·390·768·769·881·961·1024·1440px에서 실행해요(지역 수 × 5메뉴). 큰 변경은 브라우저 확대 125·150·200%와 브라우저 글꼴 크기 20·24px에서도 넘침이 없는지 확인해요.
