# 화면 디자인 시스템

`style.css` 하나가 5개 메뉴(홈·대응 절차·상황별 도움·회복·보호·지원 찾기)의 모양을 모두 정해요. 새 화면이나 항목을 만들 때는 아래 부품을 그대로 쓰고, 비슷한 모양을 새 클래스로 다시 만들지 않아요. 규칙을 바꿀 때는 해당 부품의 규칙 한 곳을 고쳐요(아래에 덧붙여 덮어쓰지 않기).

목표는 **교사가 믿고 편안하게 읽는 공공서비스형 화면**이에요. 글꼴·제목 위계·버튼·안내 상자는 정돈하고, 아이보리 바탕·부드러운 그라데이션·둥근 카드·옅은 그림자·홈과 제도 목록의 아이콘처럼 기존의 따뜻한 인상은 그대로 둬요.

## 글꼴·글자 크기

- 글꼴은 **Pretendard Variable 하나**예요(`index.html`의 jsDelivr 링크). 본문·제목·버튼·숫자 모두 같은 글꼴이에요.
- 위계는 크기와 굵기를 함께 써요: 제목 700 · 라벨·버튼 600 · 본문 400. 좁은 화면 헤더의 서비스 이름 글자만 로고 글자에 맞춰 800이에요.
- 크기는 `rem`으로 적어요(브라우저 기본 16px = 1rem). 사용자가 브라우저 글꼴을 키우면 글자도 함께 커져요. 여백·테두리는 px예요.

| 토큰 | 769px 이상 | 768px 이하 | 쓰는 곳 |
| --- | --- | --- | --- |
| `--fs-h1` | 30px | 26px | 화면 제목(`.page-title`) |
| `--fs-h2` | 23px | 21px | 구역 제목(`.h2`) |
| `--fs-h3` | 19px | 18px | 카드·상황 제목(`.sub-title`, `.care-cat-title`) |
| `--fs-h4` | 17px | 16px | 묶음·접이식·목록 머리(`.block-title`, `.disclosure-title`, `.action-head`) |
| `--fs-body` | 17px | 16px | 본문 |
| `--fs-sm` | 15px | 15px | 보조 설명·라벨(`.muted.small`, `.facts dt`) |
| `--fs-xs` | 13px | 13px | 배지 |

- 줄 간격: 본문 1.6, 제목 1.35, 버튼·목록 1.4.
- 줄바꿈: 제목(`h1`~`h4`)과 가운데 정렬 버튼 글자(`.btn-label`)는 `text-wrap: balance`, 카드·줄 제목(`.link-row-title`·`.action-label`·`.step-title` 등)과 문단은 `text-wrap: pretty`예요. 카드·줄 제목에 balance를 쓰면 ‘청구서·서식’처럼 묶인 말이 가운뎃점에서 갈려서, 마지막 줄에 한 단어만 남는 것만 막는 pretty를 써요.
- 연락처 카드(대표 번호·학교급별 번호·전화하기)는 지역마다 번호 길이가 달라 칸에 맞춰 둔 기존 크기를 그대로 써요(좁은 화면 역할 이름 13px, 히어로 번호 21px, 전화하기 15px).
- 화면 글자 속 번호(전화번호·‘제2026-200호’ 같은 문서 번호)는 `T()`가 모두 `.nowrap`으로 묶어 ‘052-’ / ‘243-8722’처럼 갈라지지 않아요(지역 토큰 값·데이터 문장·근거 제목 모두). 버튼 안 번호(`.btn-sub`, `.btn-num`)도 줄바꿈하지 않고, 칸이 모자라면 번호 전체가 다음 줄로 가요.

## 색

아이보리 바탕(`--bg`) + deep teal(`--primary`, 기본 행동·선택) + warm orange(`--accent`, 주의) + red(`--danger`, 긴급만). `--faint`는 흰 바탕 대비가 3.2:1이라 글자에는 쓰지 않고 아이콘·글머리표에만 써요.

## 간격

- 상세 안의 갈래(안내 상자·묶음·라벨·내용 목록) 사이는 12px, 묶음 안쪽 여백은 16px·18px(좁은 화면 14px·16px).
- 라벨·내용 목록은 줄마다 위아래 8px + 얇은 선. 바로가기 줄은 높이 48px(터치 영역), 줄 사이 6px.
- 여백을 늘려 정리하지 않아요. 읽기 쉬워지는 것은 글자 크기·굵기·제목 줄 분리 덕분이어야 해요.

## 부품

| 부품 | 클래스 | 규칙 |
| --- | --- | --- |
| 카드 | `.action`, `.support-item`, `.block` 등 | 흰 면 + 1px `--border` + 12px 모서리 |
| 큰 패널 | `.tool-panel`, `.hub`, `.proc-panel`, `.result`, `.region-panel` | 14px 모서리 + 옅은 그림자(`--shadow-soft`). 펼친 목록·카드에 마우스를 올렸을 때도 같은 그림자 |
| 버튼 | `.btn` + `.btn-primary`·`.btn-secondary`·`.btn-danger` | 높이 48px 이상, 16px/600, 8px 모서리. 글자는 한 줄이 기본이고 칸이 모자랄 때만 줄을 바꿔요 |
| 선택 버튼 | `.chip` | 필터·지원 유형·비교표 열기. 둥근 알약 모양, 개수는 같은 줄의 보조 숫자(`.chip-count`). 안에 배지를 넣지 않아요 |
| 배지 | `.badge`, `.badge-accent`, `.tag-danger`, `.bf-badge`(`.bf-cond`·`.bf-scope`) | 6px 모서리의 13px 이름표. 상태·조건을 알릴 때만 쓰고 **버튼 안에 넣지 않아요** |
| 바로가기 줄 | `<ul class="link-list">` + `.link-row` | 제목(`.link-row-title`) + 보조 글(`.link-row-meta`, 조건·설명) + 이동 아이콘. 회복·보호 제도 줄은 제목·조건을 한 줄로, 지원 유형 줄(`.link-row-stack`)과 좁은 화면의 허브 바로가기는 늘 제목 위 · 설명 아래 두 줄로 그려 한 목록의 줄 높이를 맞춰요. 회복·보호 제도는 `benefitChip()`, 지원 유형은 `supportChip()`이 만들어요. 넓은 칸에서 여러 열은 `.link-list.cols`. 줄 폭이 260px 이하(320px 화면)면 컨테이너 쿼리로 목록의 모든 줄이 함께 두 줄 모양이 돼요(글자 수에 따라 줄마다 모양이 섞이지 않게) |
| 접이식 | `<details class="disclosure disclosure-box">`(따로 선 묶음) · `disclosure-line`(카드 안) · `hub-fold`(지원 찾기 허브, 좁은 화면) | 요약 줄은 `disclosureHead(제목, 보조 설명)`로 만들어요. 제목 · 보조 설명 · 펼침 아이콘이 각각 분리되고 요약 줄 전체가 누르는 영역이에요 |
| 안내 상자 | `callout(kind, 제목, 문장 또는 목록)` | 제목은 따로 한 줄. `info`(지금 먼저 할 일·다음 단계) · `caution`(주의할 점·꼭 확인하세요·피해야 할 행동) · `danger`(즉시 안전 확보가 필요한 상황의 먼저 할 일) · `note`(놓치기 쉬워요·적용 범위·판단할 때 참고할 점) |
| 묶음 | `.block` + `.block-title` + `.block-desc` | 상세 안의 작은 갈래(함께 확인할 제도·연결 가능한 지원·지금 해볼 일·지역 기준). 내가 직접 쓰는 회복·보호 제도 묶음은 `.block-warm`(따뜻한 바탕), 기관 지원 묶음은 흰 바탕 + 테두리 |
| 라벨·내용 목록 | `facts(rows)` → `<dl class="facts">` | 줄마다 얇은 선. 칸이 520px보다 좁으면(컨테이너 쿼리) 라벨이 위로 올라가요 |
| 펼침 아이콘 | `.chevron`(아래), `.chevron.right`(이동) | 모든 접이식·목록 머리·바로가기 줄이 같은 아이콘을 써요 |
| 번호 카드 | `.step-row`(홈 대응 절차 4단계), `.first-card`(공통 모드 지금 먼저 할 일) | 첫 줄 = 번호(`--num-size` 30px 원) · 제목 · (진행 배지) · 화살표, 둘째 줄 = 설명. 번호·화살표는 제목 **첫 줄** 가운데에 맞춰요. 한 줄의 카드 높이가 같아져도 내용을 가운데로 모으지 않아, 설명이 1·2·3줄이어도 제목이 위아래로 움직이지 않아요 |
| 교육지원청 찾기 | `.finder-grid` + `.finder-label`·`.finder-select`·`.finder-note`·`.result`/`.finder-hint` | 이름표 → 고르기 → 관할 안내(작은 보조 글, 상자 없음) → 결과. PC(1024px~)는 오른쪽 결과가 고르기 상자와 같은 높이에서 시작하고, 고르기 전 안내는 고르기 상자 한 줄 높이만 차지해요 |

## 상황 상세 배치(PC)

1024px 이상에서는 상세 안의 묶음을 같은 순서(먼저 할 일 → 피해야 할 행동 → 판단 참고 → 해볼 일 → 알릴 내용·기록 → 회복·보호 제도 → 연결 가능한 지원 — ‘하지 말 것’을 ‘먼저 할 일’ 바로 다음에 둬요. 좁은 화면도 같은 순서)로 **두 단에 흘려** 두 단 높이를 자동으로 맞춰요(`columns: 2`, 묶음은 중간에서 끊지 않음). 상황마다 내용 길이가 달라 왼쪽·오른쪽을 고정하면 한쪽이 크게 비었기 때문이에요. 묶음 사이 간격은 아래 여백으로 줘서 두 단의 첫 상자 윗선이 맞아요. 좁은 화면과 인쇄는 한 단이에요.

## 하지 않는 것

- 지원 찾기 ‘바로 이용하기’에 시·도교육청 **일반 홈페이지** 카드를 두지 않아요. 교육활동 보호 전용 신청·상담·안내(`R.links`)와 내 교육지원청 찾기만 둬요. 일반 홈페이지는 푸터 ‘최신 안내 확인’ 문장에만 있어요.

- 새 장식(이모지·그라데이션·자동 애니메이션)을 더하지 않아요. 히어로·첫 화면의 옅은 그라데이션은 그대로예요.
- 아이콘은 컬러 이모지 대신 단색 선형 아이콘 하나의 규칙만 써요(2026-10-27): `app.js`의 `ICONS`(24×24 viewBox, 선 1.8, 끝 둥글게, 22px), 색은 청록(`--primary`)이고 긴급 입구(‘지금 해야 할 대응 확인’) 하나만 경고색(`--danger`). 하단 메뉴·홈 입구 카드·놓치기 쉬운 제도·회복·보호 목록이 같은 모양을 써요. 아이콘은 장식이라 `aria-hidden`이고 이름은 옆 제목이 맡아요. 데이터(`HOME_ENTRIES`·`BENEFITS`)의 `icon`은 `ICONS` 이름이어야 하고 `tools/check-data.js`가 대조해요.
- 지원 이름 끝의 괄호 설명(예: ‘교원보호공제(○○학교안전공제회)’)은 화면에서만 이름 아래 보조 줄(`.title-note`)로 나눠요. 데이터·검색·공유·화면 읽기 이름은 원래 이름 그대로예요. 괄호가 이름 가운데 있으면(예: ‘교원보호(안심)공제’) 나누지 않아요.
- 버튼 안에 이모지와 배지를 겹쳐 넣지 않아요(링크 복사·인쇄하기도 글자만).
- 한 열짜리 grid는 `grid-template-columns: minmax(0, 1fr)`로 적어요(`1fr`이면 띄어쓰기 없는 긴 기관명이 칸을 밀어내요).

## 점검

화면 코드를 고치면 `tools/ui-check.js`를 360·375·390·768·769·881·961·1024·1440px에서 실행해요(지역 수 × 5메뉴). 큰 변경은 브라우저 확대 125·150·200%와 브라우저 글꼴 크기 20·24·32px에서도 넘침이 없는지 확인해요.

`ui-check.js`의 ‘유형 선택 위치’(좁은 화면에서 허브 끝 → 첫 지원 유형 버튼 80px 이내)는 기본 글꼴 16px 기준이에요. 브라우저 글꼴을 키우면 사이의 제목 글자도 함께 커져 이 기준을 넘을 수 있으니, 그때는 간격을 rem으로 환산해(80px = 5rem) 판단해요.
