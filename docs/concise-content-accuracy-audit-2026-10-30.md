# 2026-10-30 「선생님 곁에」 간결한 안내·내용 정확성 1차 전수 점검

> 이 문서는 **내부 감사 기록**이다. 공개 업데이트 목록(`data/updates.js`), UI·UX, 신규 프로그램 수록을 수정하지 않는다.
> **검토 범위 구분:** 12개 지역 161개 지원 프로그램의 데이터 필드와 표현을 한 번씩 확인했고, 선택된 핵심 사항만 공식 1차 자료에 직접 대조했다. **161개 사업의 원문 전체를 오늘 독립 검증했다는 뜻이 아니다.**

## 검토 원칙

1. 교사가 실제로 놓치기 쉬운 **신청 선행 조건·돈·기한·담당 경로**만 주요 설명에 둔다.
2. 기존 상세 필드에 이미 있는 예외/약관 설명은 추가로 늘리지 않는다.
3. 추정 전화번호·신청조건·지원금·기간은 절대로 추가하거나 확정하지 않는다.
4. UI 구조·메뉴·기능·공개 업데이트 내역은 변경하지 않는다.
5. 공식 근거를 재확인하지 못한 내용의 `verifiedAt`은 올리지 않는다. 관련 조건에 새로운 증빙이 없으면 기존 기록을 유지한다.

## 3. 이번에 직접 재확인한 공식 1차 자료

### 제주: 심리지원 운영 계획

- 제주특별자치도교육청 2026년 「교(직)원 심리지원 세부 운영 계획」(2026-06-29 게시)
  https://www.jje.go.kr/forteacher/board/view.jje?boardId=BBS_0000268&dataSid=1473523&menuCd=DOM_000000705003000000&paging=ok&startPage=2
- 2026년도 정신건강의학과 진료비 **1인 연 50만 원**. 3차 집중 청구 **2026. 12. 1.~12. 7.**. `data/regions/jeju.js`의 기존 `timing`에는 **진료 전 신청 필요**로 기재되어 있음.
- 그 조건을 놓치지 않도록 `sum` 한 곳에만 반영. `amount/eligibility/timing/apply/validUntil`에는 변화 없음.

### 경남: 외부기관 연계 심리상담·치료

- 경상남도교육청 교육활동보호센터 「외부기관 연계 상담 안내」
  https://www.gne.go.kr/forteacher/counseling/outside.jsp
- 공식 공개 페이지에서 **전문상담사에게 사전 신청**, **1인 100만 원 이내**, **최초 신청 이후 2년 이내**를 확인.
- 2026년도 비용의 연말 청구 마감 **12월 초**는 기존 감사 자료 `docs/12-region-final-accuracy-audit-2026-10-26.md`의 교원보호센터 2026 안내 원문 대조 기록 및 `data/regions/gyeongnam.js`의 기존 `timing`에 근거. **정확한 날짜는 원문에서 확보되지 않았으므로 날짜를 만들어 쓰지 않는다.**
- `validUntil=2026-12-31`과 비용 청구 마감을 같다고 오해하지 않도록 `sum` 간결화. 이미 있는 신청/자격/제외 조건을 그대로 유지.

### 경기: 신규 지원사업 누락 후보(공개 카드 추가하지 않음)

- 경기도교육청교직원복지센터 「2026년 마음건강 증진사업 운영 안내」
  https://gew.kr/gew/cm/cntnts/cntntsView.do?cntntsId=1652&mi=10953
- 경기도교육청 소속 **교직원** 대상 별도 마음건강 상담·진료비(상담사 진료 권고, 2026. 3. 23. 이후, 최대 30만 원, **2026. 11. 30. 신청 마감**, 예산 소진 시 조기 종료).
- 기존 경기 카드 `교원 마음건강 지원`은 경기교권보호지원센터 경로 중심이며 교직원복지센터 연계를 언급함. 별도 금전지원·절차가 충분히 안내되는지는 중복성·실제 신청 가능 여부를 확인한 뒤 판단.
- **이번에는 12번째 프로그램을 추가하지 않는다.** 161개 현행 목록 유지.

## 4. 안전성 확인 범위와 배포 게이트

- 변경 파일: 제주/경남 지역 데이터의 기존 프로그램 **요약 두 문장**과 본 내부 감사 문서만.
- `data/updates.js` **미변경** — 이번 조정은 새 법령/지원 제도 발표가 아니라 이미 있는 조건을 눈에 잘 띄게 한 수정.
- 화면 구조·디자인·로직·금액·대상·전화번호·기간 데이터·`verifiedAt`은 **미변경**.
- 최소 수정이라도 `check-all`, UI 540조합, 변경된 카드 텍스트·기존 정보 보존 검사를 통과한 뒤에만 배포.
- 모든 외부 공식 링크의 실제 열람·전화 연결은 별도 검증 작업. 자동 링크 PASS가 사업의 진실성을 증명하지 않음.
