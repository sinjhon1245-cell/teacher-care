## 4. 후속 처리 및 배포 통제

1. 기존 로컬 작업에서 진행 중이라는 **공통 법령 1 + 지역 묶음 7** 원문 검증 결과를 먼저 수합한다. 이번 독립 점검으로 완료 처리하거나 겹치는 지역 문서를 덮어쓰지 않는다.
2. 대전 042-1395 시간·법률 직통번호 충돌, 경남 공제회 인증서, 2026/2027 지원기간 및 미해결 46+37건은 기존 gap 추적을 유지한다.
3. 원격 `main`의 README 및 연례 점검표에는 '대전 작업 브랜치/미배포'가 남아 있고 체크리스트 데이터 파일 목록에서 `daejeon.js`가 누락됐다. 선행 로컬 세션에서 이미 수정했다는 기록이 있어 **이 독립 브랜치에서는 중복 수정하지 않았다**.
4. 새 데이터 변경이 확정되면 `node tools/check-all.js`, `tools/ui-check.js`, 모바일 320px/글꼴 확대 및 공유/교육지원청 찾기 흐름을 재실행한다. **이번 실행 환경에서는 저장소 전체를 로컬로 복제하지 못해 Node 검사·브라우저 회귀 검사는 재실행하지 못했다.**
5. 이 파일만 문서로 추가하고, 프로그램·전화번호·법령 내용 및 `verifiedAt`·`reviewBy`·asset version·`main`은 변경하지 않는다. **병합/프로덕션 배포 보류.**
