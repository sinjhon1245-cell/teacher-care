# 후속 접근성 수정 목록

교사 사용성 테스트(관찰)와 **별개로 확인된 접근성 결함**을 모아 두는 목록이에요. 사용자 관찰이 없어도 기준(WCAG 2.2, 자동 검사)으로 판단할 수 있는 것만 적어요.

- 사용성 테스트의 관찰 후보(검색 결과 0건, 결과의 화면 위치, 뒤로가기, 경고 발견 가능성)는 여기에 넣지 않아요. 그건 `docs/usability-walkthrough-2026-10-26.md` 3-2장과 교사 테스트 결과(`docs/usability-results-template.md`)로 판단해요.
- 고칠 때는 별도 작업 브랜치에서 화면 회귀 검사(375~1440px)를 다시 하고, 배포 전에 다시 확인해요. 고친 뒤에는 상태를 ‘완료’로 바꾸고 커밋을 적어요.
