## Phase 2. 최종 IA와 데이터 모델

```
홈 → 지금 어떤 도움이 필요하신가요?(4개 진입) · 놓치기 쉬운 제도 · 절차 요약 · 교육지원청 찾기 · FAQ
대응 절차 → 4단계(체크 저장 키 유지) + 단계별 ‘함께 확인’ 바로가기(제도·지원 링크만)
상황별 도움 → 38개 상황: 먼저 할 일 / 학교에 알릴 내용 / 남겨 두면 좋은 기록 / 주의할 점 /
             함께 확인할 회복·보호 제도(SITU_BENEFITS) / 연결 가능한 지원(SUPPORT_TYPES) / 관련 대응 절차
회복·보호(NEW) → 회복에 시간이 더 필요하다면(흐름) + 제도 검색 + 6개 묶음
지원 찾기 → 9개 유형(상담·회복 / 치료·비용 / 법률 / 수사·소송 / 교원보호공제 / 안전·경호 / 민원 대응 / 갈등조정 / 지역 교육청)
```

대응 절차는 4단계를 유지해요(체크 저장 키가 단계 번호라 5단계로 바꾸면 저장된 진행이 어긋나요).
요청 IA의 ‘안전 확보·보고·기록’은 1단계, ‘조사·보호조치’는 2단계, ‘지역교권보호위원회’는 3단계, ‘회복·후속조치’는 4단계에 대응해요.

### 회복·보호 = 스스로 사용할 수 있는 제도(`BENEFITS`)

| 묶음(`category`) | 제도 id | 근거 |
| --- | --- | --- |
| rest 잠시 쉬어야 할 때 | special-leave · sick-leave · official-sick-leave | 교원휴가 예규 제104호, 국가공무원 복무규정 제18조, 인사혁신처 예규 제225호 |
| long 회복에 더 긴 시간이 필요할 때 | disease-leave · official-disease-leave | 교육공무원법 제44·45조, 임용령 제19조, 사립학교법 제59조 |
| care 치료를 계속 받아야 할 때 | official-medical-care | 공무원 재해보상법 제4·9·22·27·54조, 시행령 제28조 |
| protect 안전하게 보호받아야 할 때 | separation · protection-request | 교원지위법 제20조, 시행령 제17·19조 |
| work 근무 환경을 바꿔야 할 때 | transfer | 교원지위법 시행령 제2조의3②3 + 지역 인사 기준 |
| return 복귀를 준비할 때 | return-to-work | 국가공무원법 제73조②③, 교원지위법 제22조②2 |

`work-adjustment`(근무 조정)는 공통·지역 공식 근거를 찾지 못해 만들지 않았어요.

필드: `id, category, t, e, employment(all·public·check), badge, keywords, notice?, scope?, d, what, who, limit, when, apply, prepare, caution?, missed(≤2), refs(COMMON_PUBLIC_SOURCES id), basis, supportLinks{q, types}`.
지역 기준은 기존처럼 지역 파일 `benefits[id]`(이번에는 회복·보호 id만)에 두고, 출처 `uses`에 `care`를 표시해요.

### 지원 찾기 = 기관·사업이 주는 지원(`SUPPORT_TYPES` + 지역 `programs`)

- 유형마다 `guide`(공통 기준: 무엇·대상·시기·신청·놓치기 쉬워요·근거)와 `care`(회복·보호 cross-link)를 둬요.
- 상담·치료·법률·공제·경호·물적 피해·조정의 지역 세부는 `programs`에만 둬요(지역 `benefits`에서 옮김, 중복 제거).
- `programs[].area`는 문자열 또는 배열(법률 + 수사·소송을 함께 하는 사업).
- 상황 → 지원 연결은 기존 `supports`(필터 값)를 `SUPPORT_TYPES.situ`로, 수사·소송·민원은 `typeTags`를 `SUPPORT_TYPES.tags`로 연결해요(필터 데이터는 바꾸지 않음).

### 검색 역할

| 화면 | 대상 | 예 |
| --- | --- | --- |
| 상황별 도움 | 사건(기존 그대로) | 욕설·녹음·담임교체·아동학대·생기부 |
| 회복·보호 | 제도(제목·키워드·요약, 입력창은 다시 그리지 않아 IME 안전) | 특별휴가·병가·공무상·휴직·요양·전보·분리 |
| 지원 찾기 | 지원 유형 칩(기존) | 상담·치료비·변호사·경호·공제 |

상황 검색어가 제도 이름이면 ‘회복·보호에서 찾아보기’ 링크만 보여 줘요(결과는 섞지 않음).

### 상황 → 회복·보호 연결 원칙

신체·성적 피해·신변 위협·심리 소진 상황에만 휴가·병가·요양을 연결하고, 민원·부당 요구·녹음·수사·소송 상황은 비워 두거나(지원 중심) 특별휴가만 둬요.
라벨은 ‘함께 확인할 회복·보호 제도’이고, 적용을 확정하는 표현을 쓰지 않아요.
