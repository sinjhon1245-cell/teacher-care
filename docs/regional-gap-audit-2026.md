# 서울·경기·인천 콘텐츠 gap audit (2026)

- 기준일: 2026-10-04 · 대상 데이터: `data/regions/seoul.js`, `gyeonggi.js`, `incheon.js` (지원 찾기 `programs`, 회복·보호 `benefits`, 교육지원청 `offices`)
- 목적: 지역마다 정보의 깊이가 어디서 다른지 내부적으로 파악하고, 다음 확인 작업의 우선순위를 정해요.
- 원칙: **공식 자료로 확인한 내용만** 적어요. 한 지역에 자료가 없다고 다른 지역 값을 옮겨 적지 않아요. 확인하지 못한 칸은 화면에서 숨겨요.

## 지역별 요약

- **서울**: 공제·법률·상담·치료비는 가장 촘촘해요. 경호(대상·서류)와 학교민원(연락 경로)이 상대적으로 얕아요.
- **경기**: 공제·법률·상담이 촘촘하고, 경호·갈등조정도 충분해요. 교육지원청별 연락처, 비정기전보 세부 요건, 학교민원 연락 경로가 얕아요. 교권보호전담관은 다시 확인이 필요해요.
- **인천**: 원스톱 창구(032-1395) 중심으로 대부분 충분해요. 전보 세부 요건과 치유·회복 프로그램 일정이 얕고, 2027. 3. 1. 관할 개편이 예고돼 있어요.
